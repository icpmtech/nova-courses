How to Configure Power Automate Desktop for RPA & Monitor Analytics

By [Your Name], [Date]

Introduction

Power Automate Desktop brings low-code robotic process automation (RPA) to your Windows machines and lets you orchestrate, schedule, and monitor your desktop flows from the cloud. In this tutorial you’ll learn how to:

  • Install and connect the PAD agent (Machine Runtime)
  • Register your machine in the Power Automate portal
  • Organize machines into groups
  • Build and run a desktop flow
  • Monitor runs and errors via the Desktop flow activity dashboard
  • (Optional) Surface deeper insights in Power BI

Prerequisites

  • A Microsoft 365 account with a Power Automate license (per-user or per-flow plan).
  • Administrator rights on the Windows PC(s) you’ll use for RPA.
  • Internet access to make.powerautomate.com.

1. Install Power Automate Desktop

  1. Go to https://aka.ms/PADDownload and download the latest installer.
  2. Run the MSI as an administrator, follow the wizard, and complete installation.
  3. Launch Power Automate Desktop and sign in with your Microsoft account.

2. Install & Connect the Machine Runtime

  1. In PAD, click Settings (⚙️) → Machine runtime.
  2. Download and run the Machine Runtime installer.
  3. During setup, select your environment (e.g. vlsn2 (default)) and sign in.
  4. When complete, you’ll see a green “Connected” banner:

3. Register Your Machine in the Cloud Portal

  1. Open the Power Automate web portal: make.powerautomate.com.
  2. In the left nav, go to Machines → Machines.
  3. Click + Hosted machine (or + Machine for local).
  4. Give it a friendly name (e.g. LT-2021-013) and click Save.

4. Create a Machine Group

Machine Groups let you load-balance desktop flows across multiple agents:

  1. Within Machines, switch to the Machine groups tab.
  2. Click + Hosted machine group.
  3. Name it (e.g. DemoGroupRPA) and add your machines:
  1. Assign an Access role (Owner, Admin, User) as needed.

5. Build & Run a Desktop Flow

  1. In PAD or in the portal under My flows, click New flow → Desktop flow.
  2. Give it a name (e.g. "Open a web page – Agris Demo") and click Create.
  3. In the PAD designer, drag actions (Launch Chrome, Go to URL, etc.) to define your automation.
  4. Save and Run locally to test.
  5. Back in the portal under My flows, you’ll see your flow and its status:

6. Monitor Desktop Flow Activity

The Desktop flow activity dashboard gives you real-time and historical insights:

  1. In the portal’s left nav, choose Desktop flow activity.
  2. Use filters to scope by time range, errors, flows, machines, groups, run modes, or users.
  3. Key widgets include:
    • Completion status (Passed vs. Failed)
    • Runs & error rate timeline
    • Average run duration
    • Run status trends

7. (Optional) Deep-Dive with Power BI

Click Open in Power BI at the top of the dashboard to:

  • Stream a dataset into your Power BI workspace.
  • Use pre-built reports on run counts, durations, top failing steps, and more.

Conclusion

You’re now set up to run production-grade desktop flows and monitor their performance end-to-end:

  • Machines & groups give you scale and resilience.
  • Desktop flow activity keeps you on top of errors and performance.
  • Power BI unlocks advanced reporting for managers and auditors.
Happy automating! 🚀
