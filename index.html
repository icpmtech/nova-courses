Como Configurar o Power Automate Desktop e Monitorar Analytics

Automatize seus processos desktop e obtenha análises avançadas

Introdução

O que é Power Automate Desktop?

Power Automate Desktop traz automação de processos robóticos (RPA) low-code para Windows, permitindo automatizar tarefas repetitivas sem precisar de conhecimentos avançados de programação.

Neste tutorial, você aprenderá:

  • Instalar e conectar o agente PAD
  • Registrar sua máquina
  • Criar grupos de máquinas
  • Construir e executar fluxos desktop
  • Monitorar via painel de atividade
  • Usar Power BI para insights

Pré-requisitos

Antes de começar

  • Conta Microsoft 365 com licença Power Automate
  • Permissão de administrador no Windows
  • Acesso à internet ao portal Power Automate

1. Instalar Power Automate Desktop

Instalação

  1. Baixe o instalador em aka.ms/PADDownload
  2. Execute o MSI como administrador
  3. Siga as instruções do assistente de instalação
  4. Abra o PAD e faça login com sua conta Microsoft

2. Configurar o Machine Runtime

Conectar o ambiente

  1. No PAD, vá em Configurações → Machine runtime
  2. Baixe e instale o agente do runtime
  3. Faça login com sua conta Microsoft
  4. Selecione o ambiente desejado

3. Registrar sua Máquina

Processo de registro

  1. Acesse o portal do Power Automate
  2. Navegue até Máquinas → Máquinas
  3. Clique em + Máquina, dê um nome e salve
  4. O agente do runtime será associado automaticamente
Dica: Use nomes descritivos para identificar facilmente suas máquinas no painel

4. Criar um Grupo de Máquinas

Balanceamento de carga

Grupos de máquinas permitem distribuir a execução de fluxos entre vários agentes, garantindo alta disponibilidade e performance:

  1. No portal, acesse Máquinas → Grupos de máquinas
  2. Clique em + Grupo de máquinas
  3. Dê um nome ao grupo
  4. Selecione as máquinas que farão parte do grupo
  5. Salve as configurações
Deslize para cima

5. Criar & Executar um Fluxo Desktop

Criação de fluxos

Fluxos desktop são a base da automação no Power Automate Desktop:

  1. No PAD ou portal, crie um novo fluxo desktop
  2. Use o designer de fluxo para arrastar e soltar ações
  3. Configure cada ação conforme necessário
  4. Salve o fluxo e execute-o localmente
  5. Para executar em outras máquinas, use os grupos criados

6. Monitorar Atividade

Painel de atividades

Monitore a execução de seus fluxos e resolva problemas rapidamente:

  1. Abra o painel Atividade de fluxo desktop no portal
  2. Visualize todas as execuções recentes de fluxos
  3. Filtre por período, fluxo, máquina ou status
  4. Analise erros e resolva problemas quando necessário

7. Insights no Power BI

Análise avançada

Obtenha insights detalhados sobre suas automações:

  • Clique em Open in Power BI no painel de atividades
  • Visualize relatórios pré-configurados ou crie os seus próprios
  • Analise tendências de desempenho ao longo do tempo
  • Identifique oportunidades de otimização
  • Compartilhe relatórios com sua equipe
